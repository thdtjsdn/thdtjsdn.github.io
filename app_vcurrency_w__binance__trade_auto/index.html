TtwFinance 퀀트 자동매매 듀얼 엔진이란 무엇인가요?

TtwFinance 듀얼 엔진은 바이낸스(Binance) 거래소와 실시간 연동되는 고성능 알고리즘 트레이딩 플랫폼입니다. 엔진 1(autoTrading0)은 5~100단계 가변 매직라인 지지선을 기반으로 자금을 정밀 분할 매수하는 DCA 엔진이며, 엔진 2(autoTrading1)는 10대 핵심 보조지표를 실시간 멀티스레드로 분석하여 상위 10종 주도주를 1시간 주기로 스캔·스캘핑하는 초고속 단타 엔진입니다.

API Key가 서버에 저장되지 않고 어떻게 안전하게 서명되나요?

TtwFinance는 100% 클라이언트 소버린(Client-Sovereign) 설계를 채택했습니다. 입력하신 API Key와 Secret은 중앙 서버 DB에 전혀 저장되지 않으며, 사용자 로컬 PC 브라우저(Web Crypto HMAC-SHA256)에서 직통으로 암호화 서명되어 바이낸스 서버로 발주되므로 해킹이나 유출 사고가 발생할 수 없습니다.

바이낸스 API Key 발급 시 필수 보안 수칙은 무엇인가요?

반드시 'Restrict Access to Trusted IPs Only (본인 IP 지정)'를 설정하여 90일 만료 없이 영구적으로 안전하게 사용해야 합니다. 또한 'Enable Withdrawals (출금 활성화)' 체크박스는 절대로 켜지 마십시오. 본 시스템은 오직 거래/조회 권한만 사용하며 출금 권한을 일체 요구하지 않습니다.

10종 지표 퀀트 스캘핑(엔진 2)의 1시간 자동 갱신과 보유종목 분리는 어떻게 되나요?
