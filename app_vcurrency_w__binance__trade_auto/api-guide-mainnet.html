바이낸스 메인넷 API Key 발급 & 보안 필독 가이드

바이낸스 공식 사이트에서 실제 거래용 API Key를 안전하게 발급받고 100% 자금 보안을 설정하는 가이드입니다.

STEP 01

바이낸스 API Management 메뉴 이동

바이낸스 로그인 후 오른쪽 상단 프로필 아이콘 ➔ API Management 메뉴로 이동하거나 아래 직통 링크를 클릭합니다.

바이낸스 API Management 바로가기
STEP 02

API Key 생성 (System Generated)

Create API 버튼을 누른 후 System generated 옵션을 선택하고 라벨(예: TtwFinanceQuantBot)을 입력합니다. 보안 인증(OTP/이메일)을 완료합니다.

STEP 03

보안 권한 설정 (핵심 체크리스트)

1. 출금(Enable Withdrawals) 해제 필수!
API 권한 설정 시 Enable Withdrawals (출금) 항목은 절대로 체크하지 마세요. 자동매매 봇은 오직 매수/매도 권한만 필요하며, 출금 권한이 꺼져 있어 해킹 시에도 자금이 외부로 유출되지 않습니다.
2. IP 제한 설정 (Restrict Access to Trusted IPs Only) 권장
본인 PC의 IP를 등록하면 바이낸스의 90일 API 만료 정책이 자동 면제되어 영구 무제한 동작합니다. IP 제한을 걸지 않을 경우 90일마다 API를 재발급받아야 합니다.
3. 매매 권한 허용 (Enable Reading, Enable Spot & Margin Trading / Enable Futures)
사용하실 거래 모드에 맞춰 Enable Spot & Margin Trading 또는 Enable Futures 권한을 켜주세요.
STEP 04

API Key & Secret 복사 및 등록

생성된 API Key와 Secret Key를 복사하여 퀀트 봇 대시보드 화면에 입력합니다. Secret Key는 최초 발급 시 1회만 표시되므로 안전한 곳에 백업해 두세요.
