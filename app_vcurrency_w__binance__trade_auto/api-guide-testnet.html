바이낸스 테스트넷(Testnet) 모의투자 발급 가이드

실제 자산 손실 위험 없이 15,000 ~ 100,000 가상 USDT 자산으로 퀀트 자동매매를 100% 무료 테스트해보세요.

STEP 01

선물(Futures) 테스트넷 API 발급 방법 (추천)

바이낸스 선물 테스트넷 공식 사이트에 접속한 후 기존 계정이나 이메일/GitHub 계정으로 간편 로그인합니다.

바이낸스 선물 테스트넷 바로가기 (가상 USDT)
가상 자산 무상 자동 지급
로그인 시 약 15,000 ~ 100,000 가상 USDT가 무료로 계정에 충전됩니다.

로그인 후 화면 하단 API Key 섹션에서 Generate API Key 버튼을 클릭하고 생성된 API Key와 Secret Key를 복사합니다.

STEP 02

현물(Spot) 테스트넷 API 발급 방법 (선택)

현물 거래 모의투자를 진행하시려면 바이낸스 현물 테스트넷 사이트에서 GitHub 계정으로 로그인 후 Generate HMAC-SHA256 Key를 클릭하여 발급받으실 수 있습니다.

바이낸스 현물 테스트넷 바로가기
STEP 03

퀀트 봇 대시보드에서 등록 및 실행

거래 환경 설정 체크리스트
1. 거래 환경 드롭다운에서 [바이낸스 선물 테스트넷] 또는 [바이낸스 현물 테스트넷] 선택
2. 발급받으신 테스트넷 API Key와 API Secret 입력
3. [잔고 조회] 버튼을 눌러 모의 USDT 가상 잔고가 정상 조회되는지 확인
4. [자동매매 시작] 클릭하여 실시간 퀀트 매매 테스트 진행!
퀀트 자동매매 대시보드로 돌아가기
