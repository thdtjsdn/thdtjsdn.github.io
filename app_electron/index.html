설치 및 정상 실행 순서

다음 과정을 순서대로 완료해야 바이너리가 에러 없이 정상 작동합니다.

1

1. ZIP 다운로드 및 해제

GitHub 레포지토리에 접속해 Code → Download ZIP을 클릭한 뒤 원하는 로컬 폴더에 압축을 풉니다.

2

2. resources.dll 다운로드

대용량 파일 업로드 제한으로 분리된 resources.dll 다운로드 페이지로 이동하여 우측의 Raw 다운로드 아이콘을 클릭해 내려받습니다.

3

3. 파일 덮어쓰기 (필수)

따로 다운로드한 resources.dll 파일을 1단계에서 압축 해제한 폴더의 루트 디렉토리에 복사하여 기존 파일을 덮어쓰기(교체) 합니다.

4

4. 프로그램 실행

정상 실행 준비가 완료되었습니다! 폴더 내의 App - Main.exe, App - YoutubeAnalysis.exe 또는 TtwBrowser.exe 중 원하시는 앱을 실행하세요.
