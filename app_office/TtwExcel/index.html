핵심 강점: JavaScript 셀 스크립팅

기존의 스프레드시트 공식은 복잡한 조건문이나 알고리즘을 처리하기에 매우 답답하고 한계가 명확했습니다. TtwExcel은 셀 안에서 표준 JavaScript 코드를 그대로 실행하여 정교한 연산을 손쉽게 구현합니다.

  • 직관적인 프록시 참조 Cell.A0, Cell.B1 등 직관적인 속성 호출 문법이나 getCell('A0') 호출 방식을 이용해 다른 셀의 연산 결과 값을 실시간으로 호출하고 계층 연산에 통합합니다.
  • 풍부한 프로그래밍 제어 변수 선언, 조건문(if-else), 루프 반복문(for/while), 정규식(Regex)을 이용한 문자열 필터링, 그리고 Math.sqrt() 등의 수학 연산까지 완벽히 구동됩니다.
  • 웹 워커(Web Worker) 독립 실행 수백 수천 개의 계산 수식들은 브라우저 UI 스레드와 완전히 분리된 백그라운드 Web Worker 내에서 샌드박싱 연산되므로 복잡한 로직 하에서도 버벅임 없는 60fps 인터랙션을 유지합니다.

다양한 생산성 도구 기능

TtwExcel은 단순한 연산 가동뿐 아니라 웹 업무 생산성 향상에 기여할 수 있는 풍부한 데스크톱 급 스프레드시트 핵심 기능을 완벽하게 지원합니다.

초고성능 가상 그리드

방대한 셀 데이터 탐색 시에도 60fps 주사율을 유지하며, 단축키 지원과 실시간 마우스 드래그 셀 선택 영역 지정, 행/열 삽입 및 삭제, 병합/분할 기능이 매끄럽게 작동합니다.

Gzip 압축 데이터 저장

네이티브 CompressionStream API를 탑재하여 시트 설계 구성을 .json.gz 파일로 압축 다운로드하고 업로드 복원합니다. LocalStorage 자동 백업도 제공합니다.

로컬 PC 시스템 글꼴 로드

브라우저의 최신 queryLocalFonts API를 활용하여 디바이스에 설치된 나눔고딕, 맑은 고딕, 프리텐다드 등의 오프라인 글꼴들을 실시간 탐색해 서식 지정에 바로 사용합니다.

정교한 셀 스타일 지정

개별 폰트 크기, 볼드/이탤릭, 배경색 및 글자색 컬러 피커는 물론 이중선, 점선, 실선 등 다채로운 테두리 스타일(Borders) 및 다크/라이트 테마 전환 기능을 제공합니다.

RFC 4180 표준 CSV 지원 및 예외 파싱

셀 내부에 줄바꿈 개행문자(\n)나 큰따옴표(Escaped Quotes)가 포함된 까다로운 CSV 파일까지 예외 없이 엄격하게 표준 스펙대로 분리 가공하고 완벽하게 파싱합니다.

모던 다크엔진 스프레드시트 인터페이스

부드럽게 마우스 오버하고 드래그하는 하이엔드 테마 스타일의 가벼운 웹앱입니다. 클라이언트 전용 정적 번들 형태로 배포되어 속도가 압도적입니다.
