자주 묻는 질문 (FAQ)

TtwFinance 바이낸스 실시간 퀀트 시스템 가이드

라인 레이스 시리즈 중 어떤 것이 가장 가벼운가요?
BinanceEChartLineRaceTimeReloadRealTimeCanvas 버전이 압도적으로 가장 가볍습니다. ECharts 1MB나 p5.js 800KB 같은 무거운 외부 라이브러리 없이 순수 Canvas2D와 백그라운드 Web Worker 스레드로 분리되어 메인 브라우저 CPU 점유율이 0%에 가깝습니다.
2D 스캐터와 3D 스캐터의 차이점은 무엇인가요?
2D 스캐터는 거래대금(X축)과 등락률(Y축)의 평면 산점도를 실시간으로 추적하며, 3D 스캐터는 여기에 체결량/변동성(Z축)을 추가하여 Three.js WebGL로 3차원 공간에서 롱/숏 수급 역학을 입체적으로 분석합니다.
여러 개의 시스템을 동시에 띄워도 무겁지 않은가요?
네, 모든 시스템은 공통 shared/define.js 및 네이티브 W3C 표준 기반으로 설계되어 메모리 누수와 가비지 컬렉션(GC) 부하가 최소화되어 있어 여러 탭을 동시에 실행해도 원활하게 작동합니다.
선물(Futures)과 현물(Spot) 전환이 가능한가요?
네, 상단 내비게이션 바(NavHeader)의 마켓 모드 토글을 통해 USDT 선물(Futures)과 현물(Spot) 시장을 원클릭으로 즉시 전환할 수 있으며, 설정값은 브라우저에 자동 영속 저장됩니다.
