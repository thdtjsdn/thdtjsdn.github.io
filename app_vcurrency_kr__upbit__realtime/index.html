Core Engineering & Performance Architecture

Web Worker 멀티스레딩

UI 메인 스레드 락(Lock) 없이 백그라운드 스레드에서 대량의 WebSocket 체결 틱과 보조지표를 실시간 병렬 연산합니다.

60 FPS OffscreenCanvas

DOM 렌더링 부하를 제거하고 네이티브 2D GPU 가속 캔버스를 활용하여 극상의 부드러운 화면 주사율을 보장합니다.

Web Audio & TTS 사운드 엔진

Web Audio API 신디사이저와 한국어 TTS 보이스 브리핑을 결합하여 화면을 보지 않고도 급변동 종목을 귀로 감지합니다.

모바일/PC 완전 반응형

2단 스마트 앱바, 슬림 HUD 캡슐, 슬라이드업 바텀시트 모달을 탑재하여 스마트폰에서도 완벽한 퀀트 트레이딩 경험을 제공합니다.
