32비트 소수 생성 가속화

Linux 환경에서의 알고리즘 최적화: 24분에서 32초로의 성능 단축 리포트 (Part I)

프로젝트 서문 및 사양

본 문서는 Linux 환경에서 32비트 부호 없는 정수(uint32_t) 범위 내의 모든 소수를 가장 빠른 속도로 생성하기 위한 C 프로그래밍 여정을 기록합니다.

  • 데이터 포맷: 4바이트당 소수 1개 저장 (리틀 엔디안)
  • 무결성 검증: SHA-256 해시 272eb05aa...56e15
  • 하드웨어 제약: 메모리 사용량 1GB 이내 엄수
  • 정확성 원칙: 2보다 큰 어떤 수도 사전에 검증하지 않고 소수로 간주하지 않음

1단계: 시행 나눗셈 (Trial Division)

가장 기본이 되는 알고리즘으로, 수 n이 √n 이하의 소수들로 나누어 떨어지는지 확인합니다.

// n이 소수인지 확인합니다.
// primes: 2부터 n의 제곱근까지 순서대로 나열된 소수 배열
bool is_prime(uint32_t n, uint32_t* primes) {
    for (size_t i=0; ; i++) {
        uint32_t p = primes[i];
        if (n % p == 0) return false;
        // p*p 오버플로우 방지 및 소수 판정 종료
        if (p >= 0xFFFF || p*p >= n) return true;
    }
}

시간 복잡도: O(n√n / log n). 전체 2^32-1 범위를 탐색하기 위해 약 2억 개의 공간을 할당합니다.

실행 시간: 약 24분 20초

2단계: 휠 인수분해 (Wheel Factorization)

명백한 합성수(2, 3, 5의 배수 등)를 사전에 제거하여 확인해야 할 후보 숫자를 줄입니다.

  • 원리: 30($2 \times 3 \times 5$)을 법으로 하여 30과 서로소인 숫자들만 검사합니다.
  • 효과: 전체 자연수의 약 26.6%만 소수 후보군으로 선정됩니다.
// 서로소 기반 휠 순환 알고리즘
uint32_t last = wheel_last(wheel);
uint32_t turn = 0;
while (true) {
    for (size_t i=0; i < wheel.n_spokes; i++) {
        uint32_t n = wheel.size * turn + wheel.coprime_spokes[i];
        if (is_prime(n, primes)) {
            primes[p_idx++] = n;
        }
        if (n == last) goto exit_loop;
    }
    turn++;
}

실행 시간: 약 23분 30초. 검사 대상은 줄었으나 실제 속도 향상은 미미함.

3단계: 에라토스테네스의 체 (Sieve of Eratosthenes)

합성수를 지워나가는 방식으로 시간 복잡도 O(n log log n)을 달성합니다.

비트 배열(Bit Array) 최적화

4.3GB의 메모리 대신 비트 단위 저장을 통해 537MB로 메모리 사용량을 단축했습니다.

struct BitArray list = bitarray_init((size_t)0xFFFFFFFF);
for (uint32_t p = 2; p <= 0xFFFF && p*p <= 0xFFFFFFFF; p++) {
    if (bitarray_get(list, p)) continue;
    // p의 자기 자신을 제외한 모든 배수 소거
    for (size_t i=2; i <= 0xFFFFFFFF / p; i++) {
        bitarray_set(&list, i*p, true);
    }
}

실행 시간: 약 32초 (이전 방식 대비 40배 이상 향상)
