Subject 02

제2과목: 데이터분석 기획 (Analytics Planning)

분석 과제를 체계적으로 발굴하는 4가지 사분면 프레임워크, 하향식·상향식 접근법, 글로벌 표준 분석 방법론(CRISP-DM, KDD, 빅데이터 5단계), 그리고 전사 차원의 마스터 플랜 수립과 거버넌스 조직 설계 체계를 정복합니다.

출제 문항: 10문항 (20점)
목표 득점: 8~10문항 (안정적 합격 견인 과목)
과락 방어 기준: 4문항 이상 필수
01

분석 과제 발굴 4사분면 매트릭스

분석 대상(What) × 분석 방법(How) 2x2 분류 체계

기업에서 분석 프로젝트를 기획할 때, "무엇을 분석해야 하는지(분석 대상)"를 알고 있는지, 그리고 "어떤 방법으로 풀어야 하는지(분석 방법)"를 알고 있는지에 따라 분석 접근법을 4가지 유형으로 명확히 구분합니다. 시험에 매회 출제되는 최우선 핵심 개념입니다.

분석 과제 도출 4사분면 프레임워크 (Known vs Unknown)
최적화 (Optimization)
1사분면
대상: Known (앎) / 방법: Known (앎)
문제도 알고 분석 방법도 이미 확보되어 있는 상태입니다. 기존 프로세스의 효율성을 극대화하고 파라미터를 미세 튜닝하여 성과를 높이는 분석입니다.
솔루션 (Solution)
2사분면
대상: Known (앎) / 방법: Unknown (모름)
풀어야 할 문제는 명확히 알고 있으나, 어떻게 풀어야 할지 방법이나 알고리즘을 모르는 상태입니다. 새로운 분석 기법이나 머신러닝 솔루션을 도입하여 해결책을 찾습니다.
통찰 (Insight)
3사분면
대상: Unknown (모름) / 방법: Known (앎)
구체적인 당면 문제는 없으나 기존에 보유한 뛰어난 분석 역량을 활용하여 데이터 속에서 새로운 비즈니스 기회나 예상치 못한 패턴을 도출해 내는 분석입니다.
발견 (Discovery)
4사분면 [최고 난이도]
대상: Unknown (모름) / 방법: Unknown (모름)
분석 대상도 모르고 해결 방법도 알지 못하는 상태에서, 데이터 자체를 탐색하며 새로운 문제 정의와 해결법을 동시에 찾아내는 가장 혁신적인 영역입니다.
02

과제 발굴 접근법: 하향식(Top-Down) vs 상향식(Bottom-Up)

문제 주도형(Problem Driven) vs 데이터 주도형(Data Driven)

전통적인 경영에서는 문제가 주어지면 답을 찾는 하향식 접근법을 주로 썼으나, 빅데이터 시대에는 방대한 데이터로부터 스스로 통찰을 얻는 상향식 접근법과 상호 보완적인 디자인 씽킹(Design Thinking)이 필수적입니다.

하향식 접근법(Top-Down Approach) 4단계 파이프라인
Step 01
문제 탐색 (Discovery)
비즈니스 모델 캔버스(업무, 제품, 고객, 규제) 기반으로 전사적 기회 탐색
Step 02
문제 정의 (Definition)
모호한 비즈니스 문제를 데이터로 측정 가능한 구체적 '분석 과제'로 전환
Step 03
해결방안 도출 (Solution)
기존 시스템/자체 인력 활용 vs 외주 용역/솔루션 도입 등 분석 역량 매핑
Step 04
타당성 검토 (Feasibility)
경제적 타당성(ROI), 데이터 타당성(존재 여부), 기술적 타당성 종합 검증
구분하향식 접근법 (Top-Down)상향식 접근법 (Bottom-Up)
출발점비즈니스 문제(Problem)가 먼저 주어짐다양한 데이터(Data)의 탐색에서 출발
접근 논리연역적 사고 (Deductive)귀납적 사고 (Inductive)
분석 기법 성격지도학습 (Supervised Learning)비지도학습 (Unsupervised Learning / 클러스터링)
적합한 상황원인 분석, 성과 저하 문제 해결, 목표 달성신규 사업 아이템 발굴, 이상 징후 탐지, 고객 세분화
03

대표적 분석 방법론: CRISP-DM, KDD, 빅데이터 5단계

프로세스 단계 및 단계 간 피드백 루프

성공적인 분석 프로젝트를 위해 정형화된 절차인 방법론이 필수적입니다. 특히 CRISP-DM의 6단계 순환 구조와 빅데이터 분석 방법론의 5단계 계층은 필수 암기 사항입니다.

CRISP-DM (Cross-Industry Standard Process for Data Mining) 6단계 피드백 순환
PHASE 1
업무 이해
(Business)
목표 설정, 계획 수립
PHASE 2
데이터 이해
(Data Understanding)
데이터 수집, 품질 검증
PHASE 3
데이터 준비
(Data Preparation)
정제, 변환, 데이터셋 편성
PHASE 4
모델링
(Modeling)
알고리즘 선택, 파라미터 최적화
PHASE 5
평가
(Evaluation)
비즈니스 목표 달성 검증
PHASE 6
전개
(Deployment)
운영 시스템 적용, 유지보수
피드백 루프: 업무 이해와 데이터 이해 간 상호 왕복, 데이터 준비와 모델링 간 상호 피드백이 가장 활발하게 발생합니다.
KDD 분석 방법론 5단계
  1. 데이터셋 선택 (Selection): 분석 목적에 맞는 대상 데이터 추출
  2. 데이터 전처리 (Preprocessing): 잡음(Noise), 이상값, 결측치 제거
  3. 데이터 변환 (Transformation): 차원 축소, 정규화, 변수 생성
  4. 데이터 마이닝 (Data Mining): 알고리즘 적용 및 패턴 발견
  5. 평가 및 해석 (Evaluation): 발견된 지식의 가치 검증
빅데이터 분석 방법론 5단계
  1. 분석 기획 (Planning): 비즈니스 이해 및 프로젝트 범위 정의
  2. 데이터 준비 (Preparing): 필요 데이터 수집 및 정제, 저장소 구축
  3. 데이터 분석 (Analyzing): 탐색적 데이터 분석(EDA) 및 모델링
  4. 시스템 구현 (Developing): 설계, 개발 및 시스템 연동 테스트
  5. 평가 및 전개 (Deploying): 모델 운영 및 성과 모니터링
04

분석 마스터 플랜 수립과 포트폴리오 4사분면

전략적 중요도(시급성) vs 실행 용이성(난이도) 평가 기준

수많은 분석 과제 중 무엇을 먼저 실행할지 결정하는 우선순위 평가는 한정된 자원을 효율적으로 배분하기 위한 핵심 절차입니다.

분석 과제 우선순위 결정 매트릭스 (시급성 vs 난이도)
2사분면
중장기 과제
시급성: 현재(높음) / 난이도: 어려움(높음)
경영진 관점에서 매우 중요하나 기술적·비용적 난이도가 높아 철저한 준비 후 순차 추진.
1사분면 (Quick-Win)
최우선 실행 1순위
시급성: 현재(높음) / 난이도: 쉬움(낮음)
당장 실행 가능하면서 비즈니스 효과도 즉각적인 과제이므로 가장 먼저 신속히 추진.
4사분면
최하위 순위
시급성: 미래(낮음) / 난이도: 어려움(높음)
당장 급하지도 않고 난이도도 높아 과제 채택을 보류하거나 가장 마지막에 검토.
3사분면
단기 추진 가능
시급성: 미래(낮음) / 난이도: 쉬움(낮음)
시급성은 낮으나 손쉽게 구현할 수 있어 기술 습득 및 부서 역량 강화용으로 적합.
시험 단골 함정: 우선순위 기준을 '시급성(전략적 중요도)'에 둘 경우 순서는 [3구역 ➔ 4구역 ➔ 2구역 ➔ 1구역] 식으로 관점이 달라질 수 있으므로 문제 지문의 기준 축(시급성 중심인가, 난이도 중심인가)을 반드시 확인해야 합니다.
05

분석 거버넌스 체계와 3대 조직 구조

집중형 vs 기능형 vs 분산형 조직 비교

데이터 분석이 일회성 이벤트에 그치지 않고 전사적으로 내재화되기 위해서는 조직, 인력, 인프라, 프로세스를 포괄하는 거버넌스 체계가 수립되어야 합니다.

1. 집중형 조직 구조 (Centralized)
전사 분석 전담 조직(CoE)이 모든 부서의 분석 과제를 독점적으로 총괄.
• 장점: 전사 우선순위 조율 용이, 분석 노하우 집중 및 중복 방지.
• 단점: 현업 부서의 긴급한 요구에 대한 대응 지연 가능성.
2. 기능형 조직 구조 (Functional)
별도 전담 부서 없이 각 현업 부서(마케팅팀, 재무팀 등) 내에서 자체 분석 수행.
• 장점: 현업의 도메인 지식 반영 빠름, 밀착형 문제 해결.
• 단점: 부서 간 중복 투자 발생, 전사적 전략적 시너지 부재.
3. 분산형 조직 구조 (Decentralized)
전담 조직의 분석 전문 인력을 현업 부서로 직접 파견·배치하여 협업.
• 장점: 전사 관리와 현업 밀착 지원을 동시에 충족.
• 단점: 부서 간 업무 우선순위 충돌 및 인력 관리 복잡도 증가.
분석 수준 진단: 준비도(Readiness) vs 성숙도(Maturity) 4대 진단 유형
TYPE 1
정착형 (준비도↑ / 성숙도↑)
시스템, 인력, 조직이 이미 안정적으로 구축되어 정착된 가장 이상적인 완성 단계.
TYPE 2
확산형 (준비도↓ / 성숙도↑)
조직과 인력은 갖추었으나 인프라 및 시스템 준비가 다소 미흡하여 확산이 필요한 상태.
TYPE 3
도입형 (준비도↑ / 성숙도↓)
IT 인프라 구축 등 준비는 잘 되어 있으나 분석 조직과 전문 역량의 성숙도가 낮은 상태.
TYPE 4
준비형 (준비도↓ / 성숙도↓)
인프라 준비도 낮고 분석 역량도 미비하여 기초부터 종합 마스터 플랜 수립이 시급한 상태.

2과목 핵심 빈출 퀴즈 (클릭하여 정답 및 해설 확인)

Q1. 분석 과제 발굴 매트릭스에서 '분석 대상을 알고(Known), 분석 방법을 모를 때(Unknown)' 채택하는 유형은?
정답: 솔루션 (Solution)
해설: 해결할 문제는 명확하나 방식을 모르므로 최신 분석 솔루션이나 알고리즘을 도입하여 해법을 찾는 영역입니다.
Q2. 하향식 접근법의 4단계 순서를 올바르게 나열한 것은?
정답: 문제 탐색 ➔ 문제 정의 ➔ 해결방안 도출 ➔ 타당성 검토
해설: 비즈니스 문제를 넓게 탐색한 뒤, 데이터로 측정 가능한 문제로 좁혀 정의하고, 해결책을 모색한 후 마지막에 타당성을 검증합니다.
Q3. CRISP-DM 방법론의 6단계 중 '알고리즘을 선택하고 모델의 파라미터를 최적화하는' 단계는?
정답: 모델링 (Modeling)
해설: 데이터 준비 단계의 데이터를 입력받아 머신러닝/통계 알고리즘을 훈련시키는 단계입니다.
Q4. 전사 분석 전담 조직(CoE)이 전체 부서의 과제를 총괄 통제하여 노하우 집중과 중복 방지에 가장 유리한 조직 구조는?
정답: 집중형 조직 구조 (Centralized)
해설: 본부 단위의 단일 분석 부서가 전사 과제를 일괄 기획·관리하는 형태입니다.
